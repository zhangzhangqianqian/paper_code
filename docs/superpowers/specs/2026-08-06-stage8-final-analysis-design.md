# Stage 8 冻结测试集负迁移与门控解释：最终分析设计

日期：2026-08-06  
状态：已获方案批准，待实现与验收

## 1. 目标与边界

Stage 8 的目标是在不重新训练、不重新选择模型、不修改 Stage 6-R 冻结结果的前提下，使用 Stage 7-R 已保存的测试集预测和门控张量，对 Scheme2R 的逐任务迁移收益、局部负迁移、状态相关有向路由行为和计算代价进行可复现的最终分析。

本阶段只进行后验评价和可视化，不承担以下工作：

- 不读取测试结果重新选择模型、超参数或随机种子；
- 不重新训练任何模型；
- 不将验证集诊断与测试集正式结论混合；
- 不把门控权重解释为物理因果关系；
- 不因结果不符合预期而改变预先固定的评价口径。

## 2. 冻结比较对象与输入

### 2.1 严格负迁移比较

严格比较固定为：

- 联合模型：`scheme2r`-H4；
- 单任务参照：`stl_matched`-H4；
- 协议：`full` 与 `small_sample`；
- 随机种子：2026、2027、2028、2029、2030；
- 任务顺序：`electricity`、`cooling`、`heating`、`gas`；
- 预测步：未来第 1—4 小时。

`stl_matched`-H3 是 Stage 6-R 验证集筛选中的冻结主参照，不用于严格结构匹配负迁移公式。Stage 8 使用 H4 对 H4，是为了使 STL 与 Scheme2R 在时间编码器、预测头宽度和训练协议上结构匹配，差别集中在跨任务共享机制。

### 2.2 数据来源

Stage 8 仅允许读取：

- Stage 7-R 的 `predictions_test.npz`；
- Scheme2R-H4 的最佳模型检查点和门控导出所需冻结配置；
- Stage 7.6 的 124/124 正式结果清单；
- 已完成的 124 条后验 CPU 资源测量；
- Kitakyushu 数据管线生成的时间戳、训练期温度分位点和测试期上下文标签。

脚本必须先校验协议、种子、任务顺序、目标值、测试时间戳、输出形状和冻结配置完全匹配。任一关键输入缺失或不一致时立即失败，不能跳过后继续生成不完整的正式结果。

## 3. 迁移收益定义

对于误差越小越好的指标，任务或任务子集的迁移收益定义为：

\[
G=\frac{E^{\mathrm{STL}}-E^{\mathrm{Scheme2R}}}
{E^{\mathrm{STL}}}\times100\%.
\]

其中：

- \(G>0\)：Scheme2R 相对结构匹配 STL 获得正迁移；
- \(G=0\)：没有可观察的迁移收益；
- \(G<0\)：出现负迁移。

正式输出分为三个层级：

1. 任务总体收益 \(G_i\)：每个协议下，将同一任务的 4 个预测步和全部测试时间点共同纳入误差计算；
2. 任务—预测步收益 \(G_{i,h}\)：区分四个预测步；
3. 任务—情境—预测步收益 \(G_{i,s,h}\)：按季节、温度区间或星期类型分层。

不能使用四任务平均收益代替逐任务结果。论文主结论优先引用 \(G_i\) 和 \(G_{i,h}\)，情境分层用于解释局部退化和适用边界。

## 4. 指标与零值规则

### 4.1 指标优先级

- 主要推断指标：MAE；
- 次要描述指标：RMSE、WAPE；
- 补充指标：zero-safe MAPE。

### 4.2 零值处理

- WAPE 的真实值绝对值总和为零时输出空值，并记录无效原因；
- MAPE 只在 \(|y|>\varepsilon\) 的观测上计算；
- MAPE 同时输出有效样本数、有效比例和 \(\varepsilon\)；
- 不允许用固定极小分母把零负荷样本强行转化为巨大的百分比误差；
- 正式显著性检验只基于 MAE，不对 MAPE 做显著性声明。

## 5. 统计单位与分层配对 bootstrap

### 5.1 统计单位

- 五个随机种子代表五次独立训练重复；
- 同一测试年份中的滑动窗口高度相关，不能被当作相互独立的实验重复；
- Scheme2R 与 STL 在相同种子、相同协议、相同任务、相同预测时间上进行配对比较。

### 5.2 重采样方法

正式置信区间使用分层配对 bootstrap：

1. 在五个随机种子中有放回抽样；
2. 对每个被抽中的种子，在测试时间轴内使用 24 小时循环移动块进行有放回抽样；
3. 对每个重采样样本分别计算 STL 和 Scheme2R 的 MAE；
4. 先在每个种子内计算配对差异，再对被抽中的种子等权汇总；
5. 将汇总 MAE 代入迁移收益公式；
6. 使用 bootstrap 分布的 2.5% 和 97.5% 分位数构造 95% 置信区间。

正式运行默认使用 2,000 次 bootstrap；冒烟测试可使用较少重复数，但冒烟结果不得进入论文。

### 5.3 负迁移检验

研究问题是“该任务是否发生显著负迁移”，因此采用预先规定的单侧检验：

\[
H_0:G\ge0,\qquad H_1:G<0.
\]

bootstrap 单侧 \(p\) 值按重采样收益达到或超过零的比例计算，并采用加一修正，避免有限重复时出现机械的 \(p=0\)：

\[
p=\frac{1+\#\{G^{*(b)}\ge0\}}{B+1}.
\]

同时必须报告效应量 \(G\) 和 95% 置信区间，不能只报告显著性标签。

## 6. 多重比较与负迁移率

Benjamini—Hochberg 校正按预先定义的检验族分别进行：

1. 任务总体检验族：每个协议内的 4 个任务；
2. 任务—预测步检验族：每个协议内的 4 个任务 × 4 个预测步。

不把两个协议、随机种子行或探索性情境分层全部混入一个 FDR 检验族。季节、温度和星期类型属于探索性解释，报告效应量和置信区间，不扩张为大量正式显著性结论。

每个协议输出：

- 原始任务级负迁移率：\(\#\{G_i<0\}/4\)；
- 显著任务级负迁移率：\(\#\{G_i<0\ \text{且}\ q_i\le0.05\}/4\)；
- 原始任务—预测步负迁移率：\(\#\{G_{i,h}<0\}/16\)；
- 显著任务—预测步负迁移率：\(\#\{G_{i,h}<0\ \text{且}\ q_{i,h}\le0.05\}/16\)。

## 7. 情境分层

### 7.1 季节

按预测目标时刻划分 winter、spring、summer 和 autumn。每个预测步使用自身对应的未来目标时间，而不是统一使用预测起点月份。

### 7.2 温度区间

温度区间使用训练期温度的 Q1、Q2、Q3 分位点定义 Q1—Q4 四档：

- 分位点只能从对应协议的训练集计算；
- 冻结阈值后应用于测试目标时刻；
- 输出每个协议的具体阈值和各档样本数；
- 测试期温度仅用于后验分层，不作为重新训练或模型选择依据。

### 7.3 星期类型

由于当前协议没有日本法定节假日日历，正式名称固定为：

- weekday：周一至周五；
- weekend：周六和周日。

不得写成“工作日/非工作日”，避免把法定节假日误分类后作过度解释。

## 8. 门控行为与误差关联

### 8.1 门控张量

对每个协议和随机种子导出：

- 共享强度 \(\rho\)；
- 来源分配 \(\pi\)；
- 最终有向门控 \(g=\rho\pi\)；
- 目标时间和情境标签。

门控统计按协议、任务、预测步、季节、温度区间和星期类型汇总，并报告均值、标准差、中位数、四分位数和样本数。

### 8.2 方向非对称性

对每个任务对计算：

\[
A_{ij}=g_{i\leftarrow j}-g_{j\leftarrow i},
\qquad
|A_{ij}|.
\]

同时报告带符号差异与绝对差异。带符号差异用于说明哪个方向的共享更强，绝对差异用于描述非对称程度。

### 8.3 门控—误差关联

定义单样本绝对误差改善：

\[
\Delta AE=|y-\hat y^{\mathrm{STL}}|-|y-\hat y^{\mathrm{Scheme2R}}|.
\]

\(\Delta AE>0\) 表示 Scheme2R 在该样本上优于 STL。分别计算 \(\rho\)、各来源 \(g_{i\leftarrow j}\) 与 \(\Delta AE\) 的 Spearman 相关系数，并按种子汇总均值、标准差和范围。

该分析只能称为“关联”或“同步变化”，不能声称门控权重造成了误差改善，也不能将其解释为真实能源系统中的因果流向。

## 9. 正式输出

### 9.1 表格

至少生成以下机器可读表格：

- `transfer_task_overall.csv`；
- `transfer_task_horizon.csv`；
- `transfer_context.csv`；
- `negative_transfer_rates.csv`；
- `temperature_bin_thresholds.csv`；
- `gate_summary.csv`；
- `gate_asymmetry.csv`；
- `gate_error_association.csv`；
- `resource_comparison.csv`；
- `stage8_input_index.csv`。

每张表必须包含协议、模型、候选配置、随机种子口径、样本量、指标定义和必要的有效样本数，保证可以追溯至原始预测文件。

### 9.2 原始数组

保留每个协议和种子的 `rho`、`pi`、`g`、目标时间和必要上下文标签，使用压缩 NPZ 保存。正式表格和图片必须能够从这些 NPZ 与 Stage 7-R 预测文件重新生成。

### 9.3 论文图

生成以下静态、投稿级图件：

1. 逐任务迁移收益及 95% CI；
2. 任务—预测步迁移收益热力图；
3. 季节或温度情境下的局部收益热力图；
4. \(\rho\)、\(\pi\) 与 \(g\) 的任务关系图；
5. 有向门控非对称性图；
6. 门控—误差改善关联图。

每张图至少导出 SVG、PDF 和 300 dpi PNG。颜色必须兼顾色盲可读性，正迁移与负迁移使用语义一致的发散色标；图中显示效应量，不使用星号代替完整统计信息。

## 10. 工程可靠性与失败策略

正式脚本应采用“预检—临时目录—验收—原子发布”流程：

1. 检查 Stage 7.6 通过、124/124 记录完整、资源测量完整；
2. 检查冻结比较对象、协议、种子和所有预测文件；
3. 检查 Scheme2R 门控张量可导出且形状为 `[N,4,4,4]`；
4. 在临时输出目录完成全部表格、NPZ、图件和清单；
5. 对行数、有限值、FDR 范围、样本数和输出清单执行验收；
6. 只有全部通过后才发布到正式输出目录；
7. 失败时保留失败清单和日志，不生成“passed”状态。

固定随机种子用于 bootstrap 和图形抽样。清单必须记录脚本版本、输入路径、文件校验信息、bootstrap 次数、块长度、显著性阈值、零值阈值和生成时间。

## 11. 测试与验收

实现前先增加或更新自动测试，至少覆盖：

- 三层迁移收益的手工算例；
- H4 对 H4 比较约束；
- 24 小时分层配对 bootstrap 的形状、配对和可复现性；
- 单侧 bootstrap p 值的加一修正；
- 分检验族 BH 校正；
- WAPE 零分母与 zero-safe MAPE；
- 季节、温度分位档和 weekday/weekend 标签；
- \(\rho\)、\(\pi\)、\(g\) 的形状与一致性；
- 有向非对称性和门控—误差 Spearman 关联；
- 不完整输入、错种子、错时间戳和错目标值时立即失败；
- 正式输出清单、图件格式和原子发布流程。

最终验收条件：

1. 全量测试通过；
2. Stage 8 冒烟测试通过且不训练模型；
3. 正式预检通过；
4. 正式输出可以完全从冻结输入重建；
5. 论文结论能够区分总体收益、逐任务收益、局部负迁移和计算代价；
6. 若结果不支持“缓解负迁移”，脚本仍完整输出真实结果，论文措辞相应降级，不修改实验。

## 12. 与计划书和算法结构的对应

本设计不改变 Scheme2R 算法结构，只补强 Stage 8 的评价与解释链路：

- 状态相关性由季节、训练期温度分位档和 weekday/weekend 分层检验；
- 预测步相关性由 \(G_{i,h}\) 和逐步门控统计检验；
- 方向性由 \(g_{i\leftarrow j}\) 与 \(g_{j\leftarrow i}\) 的差异检验；
- 负迁移缓解由结构匹配 STL-H4、逐任务收益和显著负迁移率直接检验；
- 轻量化由参数量、训练时间和 CPU 推理时间对照支持。

因此，Stage 8 的任务是验证已有研究承诺，而不是新增网络模块或重新寻找更优模型。
